# Ibu Dhona Arba — Education Game Center

Paket portal berisi 21 game, simulasi dan kuis HTML yang diambil dari Library. File asli disalin tanpa perubahan. JumpQuest memuat 50 soal tingkat menengah. Tautan portal tetap dapat diakses menggunakan nama file semula.

## Publikasi
1. Buat repository `game-pembelajaran` dengan README di GitHub.
2. Ekstrak ZIP. Unggah isi folder (bukan ZIP) ke branch `main`.
3. Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. Gunakan URL yang muncul pada halaman Pages.

## Catatan
Portal dapat dibuka melalui index.html. Game memiliki kode aslinya; pengujian menyeluruh gameplay tidak dilakukan. Periksa setiap game sebelum digunakan siswa. Repository publik dapat dilihat siapa saja.
